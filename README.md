# All In One — نسخه وب (رایگان)

این پوشه نسخهٔ کامل وب است. نیازی به Node یا Electron ندارد.

## اجرا روی سیستم خودت
فقط `index.html` را با یک سرور محلی باز کن (باز کردن مستقیم file:// بعضی قابلیت‌ها را محدود می‌کند):

```bash
# اگر Python داری:
python -m http.server 8080
# بعد برو به: http://localhost:8080
```

## انتشار رایگان

### GitHub Pages
1. مخزن جدید در GitHub بساز
2. همه فایل‌های این پوشه را آپلود کن
3. Settings → Pages → Branch: main → Save
4. آدرس: `https://USERNAME.github.io/REPO/`

### Cloudflare Pages / Netlify / Vercel
- پوشه را Drag & Drop کن یا به Git وصل کن
- Build command خالی بگذار (سایت استاتیک است)
- Publish directory: ریشه همین پوشه

## قابلیت‌ها
- ژورنال معاملاتی + استراتژی
- پراپ (چالش، تقویم شمسی، PDF، آنالیز)
- تم‌ها، تمام‌صفحه، PWA (نصب روی موبایل/دسکتاپ)
- بازی‌ها (حکم، بیلیارد ۸بال، گل یا پوچ، …)
- گزارش باگ (تلگرام در صورت دسترسی شبکه)

## نکات
- داده‌ها در `localStorage` مرورگر ذخیره می‌شوند
- برای پشتیبان: خروجی JSON/CSV از داخل برنامه
- تلگرام از برخی شبکه‌ها (مثل ایران بدون فیلترشکن) ممکن است مسدود باشد
- توکن ربات داخل کد است؛ برای سایت عمومی بهتر است محدود/تعویض شود
