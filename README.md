## ✨ درباره برنامه

**All In One** یک ابزار سبک و کامل برای تریدرهاست؛  
از ثبت معامله و مدیریت چالش پراپ تا تحلیل عملکرد و کمی استراحت با بازی حکم.

طراحی‌شده برای استفاده روزمره، با رابط فارسی، تم تاریک حرفه‌ای و قابلیت نصب مثل اپ روی موبایل و دسکتاپ.

## 📦 قابلیت‌ها

### 📒 ژورنال معاملاتی
- ثبت معامله با نماد، جهت، ورود، SL / TP، لات و نتیجه  
- استراتژی‌های قابل ذخیره و استفاده مجدد  
- محاسبه تقریبی سود و ضرر  
- تاریخچه و خروجی داده  

### 🏛️ مدیریت پراپ
- پیگیری مراحل چالش  
- تقویم معاملاتی **شمسی** (سبز = سود / قرمز = ضرر)  
- پنل آنالیز عملکرد  
- خروجی **PDF** از ژورنال پراپ  

### 📊 آمار و نظم
- خلاصه عملکرد و وین‌ریت  
- تمرکز روی دیسیپلین و مرور معاملات  

### 🎮 بخش بازی
- **حکم حرفه‌ای** با کارت‌های واقعی‌تر و انیمیشن روان  
- چند بازی سبک دیگر برای استراحت بین سشن‌ها  

### 🎨 تجربه کاربری
- تم‌های رنگی  
- رابط تمام‌صفحه  
- پشتیبانی PWA (نصب روی گوشی / دسکتاپ)  
- ذخیره محلی در مرورگر
